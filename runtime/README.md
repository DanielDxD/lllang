The LLLang Phase 2 C runtime (`lllang_rt.h` / `lllang_rt.c`) is the minimal host for compiled programs: reference-counted heap objects with a shared header and type descriptor (ARC), UTF-8 strings and homogeneous growable arrays as refcounted payloads, stdout printing and fatal traps, and integer parsing from strings. Link your generated object code with `lllang_rt.c`; the runtime supplies `main`, which calls your `ll_main`. Build with a C11 compiler (e.g. `cc -std=c11 -o app lllang_rt.c your_program.c`); optional smoke check: `cc -std=c11 -DLLLANG_RT_SELFTEST -o rt_test lllang_rt.c && ./rt_test`.
