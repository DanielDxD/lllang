# Manifest (`lang.toml`) and lockfile

Every LLLang package is described by **`lang.toml`** at the package root. Reproducible builds and CI use **`lang.lock`**, generated by the package manager.

## `lang.toml` sections

### `[package]` (required)

| Key | Type | Description |
|-----|------|-------------|
| `name` | string | Package id (reverse-DNS, e.g. `acme.billing`) |
| `version` | semver | Release version |
| `kind` | `app` \| `lib` | Application or library |
| `entry` | path | Main `.ll` for apps (default `src/main.ll`) |
| `description` | string | Short summary for registry |
| `license` | string | SPDX identifier |
| `authors` | array | `"Name <email>"` strings |
| `resources` | array | Asset globs embedded in `.bll` |

```toml
[package]
name = "hello.app"
version = "0.1.0"
kind = "app"
entry = "src/main.ll"
description = "Sample console application"
license = "MIT"
authors = ["You <you@example.com>"]
```

Libraries omit `entry` or use it only for examples:

```toml
[package]
name = "acme.math"
version = "1.0.0"
kind = "lib"
```

### `[dependencies]`

Map of package name → version requirement.

```toml
[dependencies]
std.io = "^0.1"
acme.math = "~1.4"

[dependencies.dev]
test.utils = "^2.0"
```

- **Runtime** dependencies ship with consumers and appear in `.bll` link graphs.
- **Dev** dependencies are used for tests/benches only; not propagated.

Version syntax: semver ranges (`^`, `~`, exact, `*` discouraged in apps).

### `[build]`

| Key | Type | Description |
|-----|------|-------------|
| `target` | string | Default triple or `native` |
| `targets` | array | Cross-compile list for CI |
| `optimization` | `debug` \| `release` | Default profile |
| `public-api` | string \| array | Globs exported to `.sbl` (libs) |
| `define` | map | Conditional compilation flags |
| `link` | array | Extra native libraries |
| `watch-debounce-ms` | integer | For `lang watch` |

```toml
[build]
target = "native"
public-api = ["src/**/*.ll"]
define = { FEATURE_X = "true" }
```

### `[workspace]`

For monorepos:

```toml
[workspace]
members = ["crates/*", "apps/demo"]
default-member = "apps/demo"

[workspace.dependencies]
std.json = "0.2.1"
```

Root `lang.toml` may contain only `[workspace]`; leaf packages have full `[package]`.

### `[sdk]`

Cross-compilation and sysroot pins:

```toml
[sdk]
version = "0.1"
components = ["llvm-22", "libc-aarch64-none"]
```

Used by `lang sdk install` and `lang build --target`.

## Example complete manifest

```toml
[package]
name = "shop.checkout"
version = "2.3.0"
kind = "app"
entry = "src/main.ll"

[dependencies]
std.http = "^0.5"
std.json = "^0.5"
acme.payments = "^1.2"

[dependencies.dev]
test.snap = "^0.1"

[build]
target = "native"
optimization = "release"

[sdk]
version = "0.1"
```

## `lang.lock`

TOML lockfile written by `lang add`, `restore`, and `update`. **Do not hand edit.**

```toml
version = 1

[[package]]
name = "acme.payments"
version = "1.2.4"
sbl = "blake3:abc123..."
sources = "https://registry.lang.dev/index/acme.payments/1.2.4"

[[package.targets]]
triple = "aarch64-apple-darwin"
bll = "blake3:def456..."

[[package.targets]]
triple = "x86_64-unknown-linux-gnu"
bll = "blake3:789abc..."
```

Fields:

- **`sbl`** — content hash of canonical `.sbl`
- **`bll`** — per-target blob hash in store
- **`sources`** — registry URL or mirror provenance

`lang restore` fails if store contents disagree with hashes.

---

## Validation rules

- `name` must match `^[a-z][a-z0-9]*(\.[a-z][a-z0-9]*)+$`
- Apps must have `entry` pointing to an existing `.ll` after scaffold
- Libraries publishing to registry must set `license`
- Dependency cycles are rejected at resolve time
- `[workspace]` members must each have their own `[package]` section

## Environment overrides

| Variable | Effect |
|----------|--------|
| `LANG_MANIFEST` | Path to alternate `lang.toml` |
| `LANG_OFFLINE` | Skip registry fetch |
| `LANG_REGISTRY` | Default registry base URL |
